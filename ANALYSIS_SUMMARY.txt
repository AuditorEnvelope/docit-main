DETAILED ANALYSIS: agent_service.py
================================================================================

WHAT IT DOES:
  Provides intelligent Q&A system with commit-backed evidence
  Answers questions about code using vector search + LLM

HOW IT WORKS:
  1. User asks: "What changed in authentication between v1 and v2?"
  2. classify_intent() → Determines question type (diff/explanation/usage/breaking)
  3. indexer.search() → Vector search finds relevant docs
  4. get_commit_diff() → Gets actual changes from database
  5. GPT-4 generates answer with context
  6. Returns AgentResponse with answer, sources, confidence

KEY CLASSES:
  - AgentResponse: Response with answer, sources, provenance, confidence
  - AgentService: Main service with query() and compare_versions() methods

KEY METHODS:
  - classify_intent(question): Classify user intent
  - query(question, repo_id, top_k): Answer question with sources
  - compare_versions(repo_id, node_path, v1, v2): Compare doc versions
  - get_commit_diff(repo_id, from_sha, to_sha): Get diff between commits

CAPABILITIES:
  ✅ Answer "what changed?" queries
  ✅ Explain code functionality
  ✅ Compare versions
  ✅ Provide commit-backed evidence
  ✅ Return sources and confidence scores

DEPENDENCIES:
  - services/indexer_service.py (vector search)
  - OpenAI GPT-4 API
  - PostgreSQL database
  - Milvus vector database

CURRENT STATUS:
  ✅ Complete and functional
  ❌ Not wired into main.py
  ❌ No HTTP endpoints
  ⚠️  Requires Milvus (not running)
  ⚠️  Requires OpenAI API key

USAGE:
  Can be run standalone: python agent_service.py "Your question"
  Example: python agent_service.py "What changed in auth between v1 and v2?"
