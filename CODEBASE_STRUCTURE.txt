FOLDER PURPOSES
================================================================================

core/
  Purpose: Core application logic
  Contains: Database, auth, event processing, quality checking
  Stability: Stable - rarely changes
  
services/
  Purpose: Business logic and integrations
  Contains: Subscriptions, overlays, payments, indexing
  Stability: Stable - well-defined interfaces
  
processors/
  Purpose: Documentation generation pipeline
  Contains: Doc generators, quality integration, endpoints
  Stability: Active - frequently improved
  
webhooks/
  Purpose: GitHub webhook handling
  Contains: Multi-org support, signature verification, JWT
  Stability: Stable - core functionality
  
utilities/
  Purpose: Helper functions and abstractions
  Contains: Code parsing, LLM providers, GitHub sync
  Stability: Stable - reusable components
  
integrations/
  Purpose: External system integrations
  Contains: Lekhak AI, Pustak frontend
  Stability: Stable - well-defined interfaces
