WHAT IS agent_service.py DOING? (DETAILED ANALYSIS)
================================================================================

FILE: services/agent_service.py (267 lines)

PURPOSE:
  Provides intelligent Q&A system with commit-backed evidence
  Answers questions about code using vector search + LLM

KEY COMPONENTS:

1. AgentResponse (lines 14-20):
   - answer: The generated answer
   - sources: List of relevant docs found
   - provenance: Commit info for each source
   - confidence: Confidence score (0-1)

2. AgentService Class (lines 22-227):

   __init__ (lines 33-42):
     - Takes indexer service and database URL
     - Initializes OpenAI API key
     - Validates OPENAI_API_KEY is set

   classify_intent (lines 48-67):
     - Analyzes user question
     - Returns intent type:
       * 'diff': "What changed between X and Y?"
       * 'breaking': "Is this a breaking change?"
       * 'usage': "How do I use X?"
       * 'explanation': Default for other questions

   get_commit_diff (lines 69-80):
     - Fetches diff between two commits
     - Queries database for changelogs
     - Returns list of changes

   query (lines 82-159): MAIN METHOD
     Step 1: Classify intent (line 103)
     Step 2: Vector search for relevant docs (line 108)
       - Calls indexer.search() with question
       - Gets top_k results (default 5)
     Step 3: Build context (lines 112-120)
       - Formats search results with sources
       - Includes commit SHA and repo info
     Step 4: Generate answer with LLM (lines 123-146)
       - Calls OpenAI GPT-4 API
       - Uses system prompt for behavior
       - Includes context in user prompt
     Step 5: Format response (lines 151-159)
       - Returns AgentResponse with answer, sources, provenance, confidence

   compare_versions (lines 161-227):
     - Compares two versions of a doc node
     - Gets both versions from database
     - Fetches changelogs between versions
     - Generates comparison answer
     - Returns AgentResponse

3. CLI Interface (lines 231-266):
   - Can be run standalone: python agent_service.py "question"
   - Initializes indexer and agent
   - Processes question from command line
   - Prints formatted response

DEPENDENCIES:
  - services/indexer_service.py (vector search)
  - OpenAI API (GPT-4 model)
  - PostgreSQL database (for changelogs)
  - Milvus vector database (for semantic search)

USAGE FLOW:
  1. User asks: "What changed in authentication between v1 and v2?"
  2. classify_intent() → 'diff'
  3. indexer.search() → finds relevant docs about auth
  4. get_commit_diff() → gets actual changes
  5. GPT-4 generates answer with context
  6. Returns answer with sources and confidence
