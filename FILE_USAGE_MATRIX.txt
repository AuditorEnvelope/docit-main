================================================================================
ACTIVE FLOW
================================================================================

USER MAKES PUSH TO GITHUB
    ↓
GitHub sends webhook to /webhook endpoint
    ↓
webhooks/webhook_multi_org.py verifies signature
    ↓
main.py process_commit_event() stores in commit_bus
    ↓
core/commit_bus.py saves to database
    ↓
core/event_consumer.py polls database (separate process)
    ↓
processors/smart_processor.py generates docs
    ↓
utilities/llm_provider_v2.py calls LLM (Gemini/Groq/OpenAI)
    ↓
utilities/universal_code_parser.py parses code
    ↓
processors/comprehensive_doc_generator.py generates detailed docs
    ↓
webhooks/github_app.py authenticates with GitHub
    ↓
Docs committed and pushed to repository

================================================================================
OPTIONAL FLOWS (Not Currently Wired)
================================================================================

AGENT Q&A FLOW:
  User asks question
    ↓
  services/agent_service.py classifies intent
    ↓
  services/indexer_service.py searches vector DB
    ↓
  utilities/llm_provider_v2.py calls GPT-4
    ↓
  Returns answer with sources and confidence

HIERARCHICAL DOCS FLOW:
  integrations/lekhak_ai_integration.py orchestrates
    ↓
  processors/hierarchical_doc_generator.py generates tree
    ↓
  services/indexer_service.py indexes docs
    ↓
  services/agent_service.py updates knowledge base
    ↓
  services/overlay_service.py merges admin edits
    ↓
  services/subscription_service.py enforces limits
