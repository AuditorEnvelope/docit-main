## Current Architecture
The system consists of a core component that handles the main functionality, including subscription services, agent services, indexer services, and overlay services. The core component interacts with the database, which is supported by PostgreSQL, MySQL, MongoDB, Redis, and Milvus. The system also includes utilities for tasks such as universal code parsing, GitHub syncing, and AI integration. The main entry point of the system is the `src/main.py` file, which contains the API routes for the hierarchical documentation system.

## Data Flow
Data flows from the core component to the database and back, with the utilities providing additional functionality to support the core component. The data flow is as follows:
- The core component sends requests to the database to retrieve or update data.
- The database responds with the requested data or confirmation of the update.
- The core component processes the data and uses the utilities as needed to perform tasks such as code parsing or AI integration.
- The utilities interact with external systems, such as GitHub or AI services, to perform their tasks.
