## Current Architecture
The system consists of a core architecture with multiple components, including services, utilities, and models/schemas. The services handle specific functionalities such as subscription, agent, indexer, and overlay services. The utilities provide additional functionality such as universal code parsing, github sync, and lekhak ai integration. The models/schemas define the structure of the data used in the system. The system uses a variety of technologies, including PostgreSQL, MySQL, SQLite, MongoDB, Redis, and Milvus for database management, and Docker, Kubernetes, AWS, GCP, Azure, Heroku, Vercel, and Netlify for deployment.

## Data Flow
The data flow in the system is as follows:
- The services (subscription, agent, indexer, overlay) interact with the database to retrieve and update data.
- The utilities (universal_code_parser, github_sync, lekhak_ai_integration, etc.) process data and provide additional functionality.
- The models/schemas (canonical_model) define the structure of the data used in the system.
- The data is then deployed using various deployment technologies (Docker, Kubernetes, AWS, GCP, Azure, Heroku, Vercel, Netlify).
