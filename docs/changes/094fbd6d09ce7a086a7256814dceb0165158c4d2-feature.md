Enhanced Documentation Generation and Analysis Capabilities
===========================================================

### Overview

This change introduces significant enhancements to the documentation generation and analysis capabilities of our system. The updates include smart processing for GitHub push events, comprehensive change analysis, and documentation creation. Additionally, we have introduced multi-provider Large Language Model (LLM) support to improve content generation. These changes aim to improve the overall efficiency and effectiveness of our system's documentation and analysis capabilities.

### Impact

The impact of this change is far-reaching, affecting several key components of our system:

* **Documentation**: The new features and updates will significantly enhance the quality and comprehensiveness of our documentation.
* **Analysis**: The introduction of comprehensive change analysis will provide deeper insights into our system's functionality and behavior.
* **GitHub Integration**: The smart processing of GitHub push events will streamline our development workflow and improve collaboration.
* **LLM**: The addition of multi-provider LLM support will enhance the accuracy and diversity of our content generation capabilities.

The following components have been affected by this change:

* `app.py`
* `gitbook_config_helper.py`
* `llm_provider.py`
* `llm_provider_v2.py`
* `processor.py`
* `smart_processor.py`

### New Features

This change introduces the following new features:

1. **Smart Processing for GitHub Push Events**: Our system can now intelligently process GitHub push events, enabling comprehensive change analysis and documentation creation.
2. **Comprehensive Change Analysis**: Our system can now perform in-depth analysis of changes, providing valuable insights into our system's functionality and behavior.
3. **Multi-Provider LLM Support**: We have introduced support for multiple LLM providers, improving the accuracy and diversity of our content generation capabilities.
4. **Documentation Creation**: Our system can now create high-quality documentation automatically, reducing the need for manual documentation efforts.

### Breaking Changes

This change includes breaking changes that may require updates to your existing code or workflows. The old LLM provider has been deprecated for backward compatibility. To migrate to the new LLM provider, follow these steps:

1. Update your `llm_provider.py` file to use the new `llm_provider_v2.py` module.
2. Configure the new LLM provider in your `app.py` file.
3. Test your application to ensure compatibility with the new LLM provider.
