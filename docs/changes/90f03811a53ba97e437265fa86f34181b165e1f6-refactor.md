# Major Codebase Restructuring and Cleanup
## Overview
This commit introduces a significant refactoring of the Lekhak AI codebase, focusing on improving the organizational structure and cleanliness of the project. The primary goal of this change is to enhance code maintainability, clarity, and project organization by grouping related modules into logical subdirectories and removing outdated files. This restructuring aims to improve the overall developer experience and make the codebase more manageable for future development.

## Impact
The impact of this change is widespread, affecting several key components of the system:
* **Code Structure**: The `src/` directory has undergone a significant overhaul, with modules relocated to logical subdirectories.
* **Maintainability**: The reorganization of the codebase improves maintainability by grouping related modules together.
* **Project Organization**: The project's organization has been improved, making it easier for developers to navigate and understand the codebase.
* **Cleanup**: A significant cleanup effort has been made, removing numerous outdated development-related markdown files and Python modules no longer used by the main application entry point.
* **Developer Experience**: The restructuring aims to improve the overall developer experience, making it easier for developers to work with the codebase.

The following components have been affected by this change:
* `src/main.py`
* `src/core/`
* `src/services/`
* `src/processors/`
* `src/webhooks/`
* `start_backend.sh`
* Project documentation files
* Various services and handlers

## Technical Details
The technical details of this change are as follows:
* The `src` directory has been reorganized, with modules relocated to logical subdirectories:
	+ `CommitBusService`, `AuthService`, and `DocumentationQualityChecker` are now in `src/core/`.
	+ `SubscriptionService` and `OverlayService` are in `src/services/`.
	+ `smart_processor` and `doc_generation_endpoint` are in `src/processors/`.
	+ `webhook_multi_org`, `webhook_handler`, and `github_app` are in `src/webhooks/`.
* The `src/main.py` file has been extensively modified to update all import paths to reflect the new modular structure.
* The `dotenv` environment variable loading has been moved to the beginning of `main.py` to ensure proper initialization.
* The `start_backend.sh` script has been updated to change the Uvicorn module reference from `app:app` to `main:app`, aligning with the file name within the `src` directory.
* 40 files have been removed from the repository, including various markdown documents and potentially deprecated or consolidated Python modules that are no longer imported by `main.py`.
