GitHub Organization Management Feature Addition
==============================================

### Overview

This change introduces a significant new feature to the dashboard, enabling users to view and manage connected GitHub organizations. The addition of this functionality expands the application's capabilities to handle organizational accounts, making it a crucial enhancement for a code analysis tool. The change includes the integration of a 'Connect Organization' modal and fetches organization data from a new backend endpoint.

### Impact

The following components and areas of the system are affected by this change:

* **Frontend**: The `DashboardPage` component has been modified to include state variables and a new `useEffect` hook to manage the organization connection flow.
* **User Interface**: The dashboard now displays connected GitHub organizations and includes a 'Connect Organization' modal.
* **Organization Management**: The application now supports viewing and managing connected GitHub organizations.
* **Backend API Interaction**: A new backend endpoint (`/auth/user-organizations`) has been introduced to fetch user's connected organizations.

The affected components include:

* `pustak/src/app/dashboard/page.tsx`
* `pustak/src/components/ConnectOrganizationModal.tsx` (usage)
* `backend_auth_service` (implied new endpoint `/auth/user-organizations`)

### New Features

The following new features have been added:

1. **Display connected GitHub organizations on the dashboard**: Users can now view their connected GitHub organizations on the dashboard.
2. **Integration of a 'Connect Organization' modal**: A new modal has been introduced to allow users to link new organizations.
3. **API call to fetch user's connected organizations**: The application now makes an API call to fetch the user's connected organizations from the backend endpoint `/auth/user-organizations`.

### Breaking Changes

There are no breaking changes introduced in this update. The new functionality is additive, and existing features remain unchanged.

### Technical Details

The implementation specifics are as follows:

* The `DashboardPage` component now includes state variables (`showOrgModal`, `connectedOrgs`, `loadingOrgs`) to manage the organization connection flow.
* A new `useEffect` hook has been added to `fetchConnectedOrgs` from the backend endpoint `/auth/user-organizations` using the user's authentication token.
* The `ConnectOrganizationModal` component is imported and will likely be rendered to allow users to link new organizations.
* Minor formatting changes were also made to the `getPlanBadge` function.

### Usage Examples

To use the new features, follow these steps:

1. Log in to the application and navigate to the dashboard.
2. Click on the 'Connect Organization' button to open the modal.
3. Enter the GitHub organization details and authenticate to link the organization.
4. The connected organizations will be displayed on the dashboard.
